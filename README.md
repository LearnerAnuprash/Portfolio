# Portfolio

A personal portfolio website built with Next.js 16, React 19, and Tailwind CSS, deployed on Cloudflare Workers via OpenNext.

## Live Site

[https://anuprash.com.np](https://anuprash.com.np)

## Tech Stack

- Next.js 16 (App Router)
- React 19
- Tailwind CSS 4
- Ant Design
- Framer Motion
- TypeScript

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Scripts

```bash
pnpm build       # Production build
pnpm lint        # Lint with ESLint
pnpm preview     # Build and preview with OpenNext for Cloudflare
pnpm deploy      # Build and deploy to Cloudflare Workers
```
